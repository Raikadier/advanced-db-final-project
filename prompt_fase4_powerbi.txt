PASO 1 — CONEXIÓN DE POWER BI A MONGODB
--------------------------------------------------------------------------------
Power BI no tiene conector nativo para MongoDB. Usa este método:

Opción A (recomendada para entregas universitarias):
  1. Instala el conector MongoDB ODBC Driver (MongoDB Connector for BI)
     — descarga desde: mongodb.com/products/bi-connector
  2. En Power BI Desktop: Obtener datos → ODBC
  3. Configura el DSN apuntando a mongodb://localhost:27017/northwind_dw

Opción B (alternativa sin instalar drivers extra):
  Exporta cada colección de MongoDB a CSV usando mongosh y luego:
  1. Abre Power BI Desktop
  2. Obtener datos → Texto/CSV
  3. Importa cada CSV como tabla separada
  Script mongosh para exportar (ejecuta uno por colección):

    mongosh northwind_dw --eval "JSON.stringify(db.fact_ventas.find().toArray())" > fact_ventas.json

  Luego convierte cada JSON a CSV con Python:
    import pandas as pd, json
    df = pd.read_json("fact_ventas.json")
    df.to_csv("fact_ventas.csv", index=False)

Opción C (Python connector para Power BI):
  1. En Power BI: Obtener datos → Python script
  2. Usa pymongo para leer y retornar DataFrames

  Ejemplo de script Python para fact_ventas:
    from pymongo import MongoClient
    import pandas as pd
    client = MongoClient("mongodb://localhost:27017")
    db = client["northwind_dw"]
    df = pd.DataFrame(list(db.fact_ventas.find({}, {"_id": 0})))

PASO 2 — MODELO DE DATOS EN POWER BI (vista Modelo)
--------------------------------------------------------------------------------
Una vez importadas las tablas, configura las relaciones:

  fact_ventas[fecha_id]       → dim_fecha[fecha_id]          (Muchos a 1)
  fact_ventas[fecha_entrega_id]→ dim_fecha[fecha_id]         (Muchos a 1, inactiva*)
  fact_ventas[cliente_id]     → dim_cliente[cliente_id]      (Muchos a 1)
  fact_ventas[empleado_id]    → dim_empleado[empleado_id]    (Muchos a 1)
  fact_ventas[producto_id]    → dim_producto[producto_id]    (Muchos a 1)
  fact_ventas[shipper_id]     → dim_shipper[shipper_id]      (Muchos a 1)
  fact_ventas[territorio_id]  → dim_territorio[territorio_id](Muchos a 1)
  dim_empleado[empleado_id]   → dim_metas_empleado[empleado_id](1 a Muchos)

  *La relación con fecha_entrega_id se activa en medidas específicas con
   USERELATIONSHIP() en DAX.

TIPO DE FILTRO: Bidireccional solo en fact_ventas ↔ dim_fecha (la activa).
El resto: unidireccional (de dimensión a hechos).

PASO 3 — MEDIDAS DAX (crea una tabla llamada "Medidas")
--------------------------------------------------------------------------------
Crea las siguientes medidas DAX esenciales:

-- Ventas totales
Total Ventas =
    SUM(fact_ventas[total_venta])

-- Número de órdenes únicas
Num Ordenes =
    DISTINCTCOUNT(fact_ventas[order_id])

-- Total unidades vendidas
Unidades Vendidas =
    SUM(fact_ventas[cantidad])

-- Margen total
Total Margen =
    SUM(fact_ventas[margen])

-- % Margen promedio
% Margen Promedio =
    DIVIDE(SUM(fact_ventas[margen]), SUM(fact_ventas[total_venta]), 0) * 100

-- Promedio días de entrega
Avg Dias Entrega =
    AVERAGEX(
        FILTER(fact_ventas, NOT ISBLANK(fact_ventas[dias_entrega])),
        fact_ventas[dias_entrega]
    )

-- % Entregas puntuales
% Entregas Puntuales =
    DIVIDE(
        COUNTROWS(FILTER(fact_ventas, fact_ventas[entrega_puntual] = TRUE())),
        COUNTROWS(FILTER(fact_ventas, NOT ISBLANK(fact_ventas[entrega_puntual]))),
        0
    ) * 100

-- Meta del período (para P5)
Meta Periodo =
    SUMX(
        RELATEDTABLE(dim_metas_empleado),
        dim_metas_empleado[meta_ventas_usd]
    )

-- % Cumplimiento vs meta (para P5)
% Cumplimiento Meta =
    DIVIDE([Total Ventas], [Meta Periodo], 0) * 100

-- Ventas período anterior (para variación YoY)
Ventas Año Anterior =
    CALCULATE([Total Ventas], SAMEPERIODLASTYEAR(dim_fecha[fecha_completa]))

-- Variación YoY
Variacion YoY % =
    DIVIDE([Total Ventas] - [Ventas Año Anterior], [Ventas Año Anterior], 0) * 100

-- Clientes activos (con compra en el período)
Clientes Activos =
    DISTINCTCOUNT(fact_ventas[cliente_id])
